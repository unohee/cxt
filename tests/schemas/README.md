# SARIF schema

`sarif-schema-2.1.0.json` is the unmodified OASIS SARIF 2.1.0 approved errata schema.

- Retrieved: 2026-09-27
- SHA-256: `c3b4bb2d6093897483348925aaa73af03b3e3f4bd4ca38cef26dcb4212a2682e`
- Specification and terms: https://docs.oasis-open.org/sarif/sarif/v2.1.0/errata01/os/sarif-v2.1.0-errata01-os-complete.html

Tests use the complete draft-04 schema with Ajv and URI formats. The schema is
vendored so test success does not depend on a live schema server.
